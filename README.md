# hmm-forge

隐马尔可夫模型（Hidden Markov Model）实验室 —— **零依赖、零构建的单文件 HTML**，在浏览器里跑完整的前向-后向 / Viterbi / Baum-Welch 算法，并自带 8 条可交叉验证的不变量自检。

打开 `index.html` 即可用，无需服务器、无需 npm install。

## 能看什么

- **词性标注解码**：内置 5 词性 × 16 词的手工 HMM，输入句子即时输出 Viterbi 最优词性序列
- **Viterbi Trellis**：δ 对数域网格，最优路径逐格高亮，ψ 回溯指针可见
- **后验边缘 γ**：前向-后向算出的 P(qₜ=i | O, λ)，堆叠条可视化
- **A / B 矩阵热图**：转移概率与发射概率，聚焦当前句子的词
- **Baum-Welch 参数还原**：从真模型采样 3000 个 token 作语料 → 随机初始化 → EM 200 轮，实时画对数似然收敛曲线，并与真值模型 LL 对比
- **不变量自检面板**：8 项硬断言，浏览器内实时计算，与无头 Node 断言跑的是同一份 engine 代码

## 算法

| 模块 | 公式 | 复杂度 |
|------|------|--------|
| 前向 α | αₜ(j) = [Σᵢ αₜ₋₁(i) aᵢⱼ] bⱼ(oₜ) | O(T·N²) |
| 后向 β | βₜ(i) = Σⱼ aᵢⱼ bⱼ(oₜ₊₁) βₜ₊₁(j) | O(T·N²) |
| Viterbi | δₜ(j) = maxᵢ [δₜ₋₁(i) aᵢⱼ] bⱼ(oₜ) | O(T·N²) |
| 后验 γ/ξ | γₜ(i) = αₜ(i)βₜ(i)/P(O) | O(T·N²) |
| Baum-Welch | E 步 γ/ξ，M 步 π/A/B 重估 | O(T·N²)/轮 |

全部在**对数域**计算（logsumexp 防溢出），因此 T=400 的长序列也不会像朴素概率域那样下溢成 0。

## 8 条不变量

| # | 不变量 | 验证套路 |
|---|--------|----------|
| 1 | 前向似然 == 后向似然 | 同一序列两种算法互检 |
| 2 | 前向 == 暴力枚举 Nᵀ 条路径求和 | 参照实现 vs 主实现 |
| 3 | Viterbi == 暴力枚举最优路径 | 暴力枚举 vs 贪心/动态规划 |
| 4 | Viterbi 对数概率 == 沿路径逐项重算 | 解析 vs 数值 |
| 5 | Baum-Welch 对数似然单调非减 | EM 定理（单调收敛） |
| 6 | Σᵢ γₜ(i)=1 且 Σⱼ ξₜ(i,j)=γₜ(i) | 概率归一 + 边缘一致 |
| 7 | 对数域 == 朴素域（T=10）；T=400 朴素域已下溢 | 数值稳定性 |
| 8 | 状态标签置换后似然不变 | 等变/不变性 |

> 状态标签只在**置换等价**意义下可识别 —— 这正是第 8 条的含义：Baum-Welch 训练出的状态编号会与真值错序，但对齐置换后 A 矩阵逐项吻合（实测 argmax 一致率 5/5，L1 = 0.76，随机模型约 3~6）。

## 无头验证

```bash
node _smoke.js   # 1395/1395 PASS，写 _smoke.log
node _probe.js   # dump 内部状态到 _probe.txt，人眼复核
```

`_smoke.js` 用 `vm.runInContext` 从 `index.html` 抽出 `<script id="engine">` 在 Node 里跑，覆盖：

- 8 条内置不变量
- 200 组随机模型（N∈[2,4], M∈[2,5], T∈[1,9]）的前向/后向/暴力/Viterbi/γ-ξ/置换交叉验证
- 边界条件：T=0、T=1、N=1、M=1、含 0 概率的转移与发射（不得产生 NaN）
- 确定性：同 seed 采样与自检结果可复现
- 5 组 Baum-Welch：LL 单调非减、真值起点 1 步 EM 不下降、训练后 LL 逼近真值（<1%）、训练后矩阵行和=1

`_probe.js` 是探针：把 α/β/δ/ψ/γ/ξ 与全部 2³ 条路径概率 dump 成 ASCII，确认「全绿 ≠ 正确」。

## 目录

```

_smoke.js     无头断言（1395 项）

```
